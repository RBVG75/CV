# Portfolio - Randall Brayan Vega Gonzalez

Portfolio personal desarrollado con HTML, CSS y JavaScript vanilla. Sitio web de una sola página con diseño oscuro, animaciones con partículas y efecto glassmorphism.

## Secciones

- **Inicio** - Presentación con avatar animado
- **Sobre mí** - Información personal, ubicación y contacto
- **Habilidades** - Lenguajes, bases de datos, BI y herramientas
- **Proyectos** - Tarjetas con proyectos destacados y links a GitHub
- **Educación** - Línea de tiempo académica

## Tecnologías

- HTML5
- CSS3 (variables, grid, flexbox, animaciones, glassmorphism)
- JavaScript vanilla (canvas particles, scroll reveal, menú responsive)
- Google Fonts (Inter)

## Vista previa

Abre `index.html` en cualquier navegador para ver el portfolio.
